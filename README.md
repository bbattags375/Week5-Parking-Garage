# Week5-Parking-Garage
Parking Garage Fee Calculator
Description
A command-line program that calculates a parking fee based on hours parked and a coupon type. The user can apply a 20% discount, a $2.00 flat discount, or a $20.00 flat rate. All pricing values are stored as constants to keep the code clean and easy to update.
What I Learned

Using named constants instead of hardcoded values
Applying discounts with if/elif conditional logic
Cleaning user input with .strip() and .lower()
Formatting currency output with f-strings

Tools Used

Python 3

How to Run
Download the file and run the following command in your terminal:
python Week5ParkingGarage2.py
